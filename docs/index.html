The fingerprint is a hash of the document state. When both sides show the same one, the replicas agree on every character and its order, which is the property that ordinary last-write-wins syncing cannot give you.

What this project actually found

Convergence is checked by randomised trials, not by example

A thousand randomised interleavings across three to ten clients, each asserted to converge. A handful of hand-written scenarios only proves the cases somebody thought of.

The demo found a bug the CRDT tests could not

The status line claimed offline edits were buffered while the send was guarded by readyState === 1 with no else branch. Offline edits were shown to the user and silently dropped. The bug was never in the CRDT, it was in never handing it the operations.

Tombstones are not free, so they are measured

Deleted characters stay as tombstones for correctness. Compaction is measured rather than assumed, because unbounded metadata growth is the standard way CRDTs become unusable.

Compared against Yjs on the same harness

The hand-rolled RGA runs the identical convergence harness as a production CRDT library, which is what makes the comparison meaningful rather than flattering.
