Collaborative plain-text editor

Open this page in two windows and type in both. Plain text only - rich text is a scope trap, and the README says why.

connecting you: - peers: 0 ops applied: 0 chars: 0

Every keystroke becomes a CRDT operation referencing the character it follows, never an index. Concurrent edits at the same position both survive and every replica orders them identically - see src/rga.mjs.
